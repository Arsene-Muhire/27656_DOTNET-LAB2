# Lab1App – Windows Forms (.NET)

A C# Windows Forms application with a login screen and two small programs:
a **Bicycle Rental** calculator and a **Mushroom Finder** guessing game.

## Requirements

- Windows 10 or 11
- [.NET 10 SDK](https://dotnet.microsoft.com/download) (the project targets `net10.0-windows`)
- Visual Studio 2022/2026 with the **.NET desktop development** workload (optional, for the designer and F5)

## How to run

**Visual Studio:** open `Lab1App/Lab1App.sln` and press **F5**.

**Command line:**

```
cd Lab1App
dotnet run
```

## Login

After logging in, the **Choose** screen lets you open either program.
Every screen has **Back** and **Logout** buttons; closing a window with **X** exits the application.

## Bicycle Rental

Enter a starting hour (0–23) and an ending hour (1–24), then click **Calculate**.
Only whole numbers are accepted, and the start must be before the end.
The total is the sum of the rate for each hour rented:

| Hours          | Rate per hour |
|----------------|---------------|
| 0–7 and 21–24  | 500 RWF       |
| 7–14 and 19–21 | 1000 RWF      |
| 14–19          | 1500 RWF      |

Example: from 13 to 16 = 1000 + 1500 + 1500 = **4000 RWF**.

## Mushroom Finder

Think of one of the six mushrooms, click **Start**, and answer **Yes** / **No**.
The program identifies it in **at most 3 questions**.

Mushrooms: Agaric jaunissant, Amanite tue-mouche, Cepe de Bordeaux, Coprin chevelu, Girolle, Pied bleu.

```
Gills?
├─ No  → Cepe de Bordeaux
└─ Yes → Grows in a forest?
         ├─ No  → Convex cup?  Yes → Agaric jaunissant   No → Coprin chevelu
         └─ Yes → Ring?
                  ├─ Yes → Amanite tue-mouche
                  └─ No  → Convex cup?  Yes → Pied bleu   No → Girolle
```

| `BicycleForm.cs` | Input validation and rent calculation |
| `MushroomForm.cs` | Yes/No decision tree |
| `*.Designer.cs` | Layout of each form (generated by the Visual Studio designer) |
